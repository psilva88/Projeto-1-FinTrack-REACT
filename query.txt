Authorization -> Bearer SEU TOKEN AQUI

Saldo por conta:
query {
  saldoPorConta {
    conta { nome tipo }
    receitas
    despesas
    saldo
    totalTransacoes
  }
}

Gastos por categoria:
query {
  gastosPorCategoria(inicio: "2026-08-01", fim: "2026-08-31") {
    categoria { nome }
    total
    quantidade
    percentual
  }
}

Resumo mensal:
query {
  resumoMensal(mes: 8, ano: 2026) {
    mes
    ano
    totalReceitas
    totalDespesas
    saldo
    quantidadeTransacoes
    gastosPorCategoria {
      categoria { nome }
      total
      percentual
    }
  }
}

Transações com relações:
query {
  transacoesComRelacoes(tipo: "despesa", limite: 10) {
    descricao
    valor
    data
    conta { nome }
    categoria { nome }
  }
}

Dashboard (a que justifica o GraphQL — traz tudo numa requisição só):
query {
  dashboard {
    saldoGeral
    saldoPorConta { conta { nome } saldo }
    gastosPorCategoria { categoria { nome } total percentual }
    ultimasTransacoes { descricao valor data categoria { nome } }
  }
}

Criar conta — POST http://localhost:3000/contas
{
  "nome": "Carteira",
  "tipo": "carteira",
  "saldoInicial": 150
}

Criar categoria — POST http://localhost:3000/categorias
{
  "nome": "Contas Fixas",
  "tipo": "despesa"
}

Editar transação — PUT http://localhost:3000/transacoes/ID_DA_TRANSACAO
{
  "descricao": "Padaria (corrigido)",
  "valor": 25.00
}

Editar conta — PUT http://localhost:3000/contas/6a89f4f9c3203df934c9b526
{
  "nome": "Nubank Principal"
}

Excluir transação — DELETE http://localhost:3000/transacoes/ID_DA_TRANSACAO
Listar — GET http://localhost:3000/contas e GET http://localhost:3000/categorias
