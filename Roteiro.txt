PASSO A PASSO

1. Extrair e configurar

Extrai por cima da pasta api-pessoas. Abre o .env e substitui COLE_AQUI_A_STRING_DO_MONGODB pela string do Bernardo (com /pessoas no fim, não /fintrack).

npm install
node src/server.js

Deve aparecer:

MongoDB conectado com sucesso!
Servidor rodando na porta 3000
GraphQL disponível em http://localhost:3000/graphql

2. Cadastrar usuário

POST http://localhost:3000/auth/cadastro

json
{
  "nome": "Maria Silva",
  "email": "maria@email.com",
  "senha": "123456"
}

3. Login

POST http://localhost:3000/auth/login

json
{
  "email": "maria@email.com",
  "senha": "123456"
}

Copia o token.

4. Testar sem token

GET http://localhost:3000/pessoas sem Authorization → deve dar "Token não informado"

5. Testar com token

GET http://localhost:3000/pessoas com Bearer Token → funciona

6. Cadastrar pessoa

POST http://localhost:3000/pessoas com token

json
{
  "nome": "João",
  "email": "joao@email.com",
  "idade": 30
}

7. Testar autorização

DELETE http://localhost:3000/pessoas/ID_DA_PESSOA com o token da Maria → 403, porque ela é usuario.

Aí vai no Atlas → coleção usuarios → muda o perfil da Maria pra admin → faz login de novo → repete o DELETE → funciona.

8. GraphQL

Abre http://localhost:3000/graphql, adiciona o header Authorization = Bearer TOKEN e roda:

graphql
query {
  pessoas {
    id
    nome
    email
    idade
  }
}
graphql
query {
  pessoas {
    nome
    email
  }
}
graphql
mutation {
  cadastrarPessoa(
    nome: "Carlos"
    email: "carlos@email.com"
    idade: 35
  ) {
    id
    nome
    email
  }
}

Tira o header e roda de novo → erro Usuário não autenticado.
